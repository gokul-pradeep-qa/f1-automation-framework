# 🏎️ F1 Automation Framework

A professional end-to-end automation framework built using Playwright and JavaScript to validate Formula 1 data through the OpenF1 API and Formula1.com.

---

## 🚀 Features

- ✅ UI Automation Testing
- ✅ API Automation Testing
- ✅ UI ↔ API Validation
- ✅ Page Object Model (POM)
- ✅ Reusable API Service Layer
- ✅ Base API Service
- ✅ Custom API Assertions
- ✅ Validators
- ✅ Response Cache
- ✅ Retry Mechanism
- ✅ Test Data Factory
- ✅ Logger
- ✅ GitHub Actions CI/CD

---

## 🛠 Tech Stack

- Playwright
- JavaScript
- Node.js
- OpenF1 API
- GitHub Actions

## ▶️ Run the Project

Install dependencies

```bash
npm install
```

Run all tests

```bash
npm test
```

Run API tests

```bash
npm run api
```

Run Smoke tests

```bash
npm run smoke
```

View HTML Report

```bash
npm run report
```


## ⚙️ Continuous Integration

Every push to the `main` branch automatically:

- Installs dependencies
- Installs Playwright browsers
- Executes the Playwright test suite
- Uploads the HTML report

Powered by GitHub Actions.
